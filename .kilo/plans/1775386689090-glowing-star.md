# Lithuanian Naturalness Research Plan

## Mission Statement

Build a Lithuanian naturalness model grounded in linguistic reality, not AI/human binary classification. The output is a calibrated scoring system and a transformation ruleset that moves text toward a specific authentic Lithuanian business register.

## Current State Assessment

- 23 human corpus samples (insufficient)
- 51% detection accuracy (needs >80%)
- Strongest known signals: particle density, copula frequency

## Phase 1: Corpus Construction (Target: 300+ samples)

### Source Tier 1 — Pre-2022 Archives (guaranteed human)

- **LRT.lt interview transcripts 2015-2021** — business/economics topics
- **Verslo žinios column archive 2010-2020** — opinion pieces, not news
- **Delfi ekonomika op-eds 2012-2021**
- **15min.lt verslas section 2012-2021**
- **Seimas stenogramos** — committee discussions on economic topics

### Source Tier 2 — Oral-origin text (speech syntax, unpolished)

- **Podcast transcripts:** Verslo klasė, Pinigų karta, any Lithuanian business podcast with transcripts
- **YouTube auto-transcripts** of Lithuanian business interviews — raw, unedited
- **Radio LRT debate transcripts** on economic topics

### Source Tier 3 — Domain-specific professional

- **Lithuanian Bar Association** published legal opinions (lawyer-written, not template)
- **Bank of Lithuania** research commentary (economist-written prose sections)
- **Lithuanian startup founder blogs** pre-2022 — startupas.lt, rytas.lt tech section

### Filtering Criteria (Apply to each sample)

- Minimum 200 words
- Written in Lithuanian (not translated from English)
- Author is a named Lithuanian person or institution
- Published before January 2023
- Not a press release or corporate template

## Phase 2: Linguistic Feature Extraction

### Morphological Features

- **Particle density per 1000 words** — broken down by particle type (juk, gi, turbūt, bene, gal, na, mat)
- **Copula frequency** (yra, buvo, bus) — your stats show this is highly discriminating (15.99 human vs 30.70 AI)
- **Reflexive verb ratio vs passive participle ratio**
- **Dropped pronoun rate** — count sentences where subject pronoun is omitted vs stated
- **Genitive chain depth distribution** — how deep do real chains go in authentic text?

### Syntactic Features

- **Average clause depth** — Lithuanian human text tends toward coordination over subordination
- **Sentence-initial element distribution** — what percentage start with verb, subject, adverb, conjunction?
- **Paragraph-final sentence length** — humans often end paragraphs with a short punchy sentence, AI ends with a summary clause

### Lexical Features

- **Concrete noun ratio vs abstract noun ratio**
- **Number/statistic density per 1000 words** — humans anchor claims in specifics
- **Direct address frequency** (jūs, tu, jūsů)
- **First person frequency** broken down by singular vs plural

### Discourse Features

- **Rhetorical question frequency**
- **Transition phrase inventory** — what transitions do real Lithuanian writers actually use vs AI's "Apibendrinant", "Nuo teorijos prie praktikos"?
- **Paragraph opening patterns** — catalogue the first 3 words of each paragraph across 300 samples

## Phase 3: Contrastive Analysis

### Matched Pair Testing

- Generate Lithuanian AI text on 20 different business topics using current Social Beast pipeline
- Same topics, same angles as human corpus
- Run statistical comparison on every feature from Phase 2

### Statistical Analysis

- **t-test for each feature:** human mean vs AI mean
- **Calculate effect size (Cohen's d) for each feature**
- **Rank features by discriminating power**

### Expected Output

- Ranked table of features where top 5-8 features explain 80%+ of the variance
- These become the new detector's primary signals
- Hypothesis: Particle density, copula frequency, dropped pronoun rate, genitive chain depth, paragraph opening pattern diversity, concrete noun ratio

## Phase 4: Register Profiling

### Clustering Criteria

- **Publication type** (journalism vs opinion vs professional commentary)
- **Author role** (journalist vs executive vs analyst vs founder)
- **Topic domain** (business strategy vs operations vs market analysis)

### Output

- Feature profile for each cluster
- Specific register profile for Social Beast's target output (direct, skeptical, business-facing)
- That cluster's feature profile becomes the scoring target

## Phase 5: Detector Recalibration

### New Scoring Architecture

```
composite_score =
  particle_score    * 0.30  (strongest signal, currently underweighted)
  copula_score      * 0.20  (second strongest signal)
  genitive_score    * 0.15  (currently pattern 5, weight 3 — needs lifting)
  pronoun_score     * 0.15  (not currently detected at all)
  vocabulary_score  * 0.10  (currently overweighted)
  uniformity_score  * 0.10  (keep as-is)
```

### Validation

- Target: >80% accuracy, <10% false positive rate on pre-2022 human text
- Validate against held-out corpus samples

## Phase 6: Transformation Ruleset Expansion

### Pattern Extraction

- Extract 50 most common AI patterns not currently in the detector
- For each pattern, find 3+ natural Lithuanian alternatives from the corpus
- Build before→after pairs with corpus-sourced examples (not invented ones)
- Weight each transformation by its score impact (from Phase 3 contrastive analysis)

### Output

- 50+ grounded before→after transformation pairs with corpus sources
- Transformation library that the rewrite LLM can use as a grounded reference
