# Lithuanian Corpus Frequency Analysis Plan

## Executive Summary

This plan outlines a comprehensive research methodology to identify measurable statistical differences between human-written and AI-generated Lithuanian text through corpus-based frequency analysis. The goal is to establish hard numerical thresholds for the lt-naturalizer detector.

## Research Objectives

1. **Quantify linguistic differences**: Measure specific statistical patterns that distinguish human vs AI Lithuanian text
2. **Establish detection thresholds**: Create numeric benchmarks for the detector based on actual corpus data
3. **Validate existing patterns**: Test the 6 Lithuanian-specific detectors against real frequency data
4. **Identify new patterns**: Discover additional AI-specific patterns through statistical analysis

## Methodology Overview

### Phase 1: Corpus Collection (Weeks 1-2)

**Human Lithuanian Corpus (20 samples minimum):**

- **News sources**: 15min.lt, Delfi.lt, Lietuvos rytas (2019-2021 pre-AI contamination)
- **Literary sources**: National Library digital collections, Vilnius University publications
- **Forum/social media**: Reddit.lt, discussion boards, authentic user-generated content
- **Administrative text**: Government documents, official communications

**AI Lithuanian Corpus (20 samples minimum):**

- **ChatGPT-4**: 20 samples with identical prompts
- **Claude**: 20 samples with identical prompts
- **Gemini**: 20 samples with identical prompts
- **Prompts**: Technology in Lithuania, AI explanation, Lithuanian winter, remote work benefits, education reform

### Phase 2: Statistical Analysis (Weeks 3-4)

**Core Metrics:**

1. **Particle Frequency Analysis** - Count dalelytės (particles) per 1000 words:
   - gi, juk, na, bent, gal, bene, vis dėlto, turbūt, mat, jau, štai, taigi, tad, taip pat, be to, iš tiesų, tiesa, aišku, žinoma, beje

2. **Copula Density Measurement**:
   - yra per 1000 words
   - buvo / bus per 1000 words
   - Register-specific analysis (formal vs informal)

3. **3-Gram Pattern Analysis**:
   - Extract top 50 most frequent 3-word sequences from each corpus
   - Identify AI-only or AI-overused patterns (5×+ frequency)

4. **Morphological Complexity**:
   - Case usage patterns (genitive chains, dative usage)
   - Aspectual prefix analysis (perfective vs imperfective)
   - Participle system frequencies

**Advanced Metrics:**

- Type-Token Ratio (TTR) comparison
- Hapax legomena rate
- Burstiness analysis (sentence length variation)
- Vocabulary richness measures

### Phase 3: Validation & Thresholds (Weeks 5-6)

1. **Statistical Significance Testing**:
   - Calculate confidence intervals for all metrics
   - Determine minimum sample sizes for reliable detection

2. **Threshold Calibration**:
   - Establish numeric detection thresholds for each pattern
   - Create register-aware scoring (formal vs informal text)
   - Validate against false positive reduction testing

3. **Pattern Integration**:
   - Update existing 6 Lithuanian detectors with corpus-based weights
   - Add new patterns discovered through analysis
   - Create a comprehensive detection matrix

## Success Criteria

1. **Statistical Significance**: All metrics show p < 0.05 significance
2. **Detection Accuracy**: 90%+ accuracy in distinguishing human vs AI text
3. **False Positive Rate**: < 5% false positives on authentic Lithuanian text
4. **Register Awareness**: Appropriate handling of formal vs informal registers
5. **Scalability**: System can process new text samples efficiently
